Design directions — player lobby

Five art directions for the logged-in lobby, each a standalone HTML file with the same content and the same token names — only the values and the surface treatment differ. Every one has a working light/dark toggle and a working EN ⇄ فارسی toggle that flips dir and mirrors the whole layout. Open them, switch both toggles, then tell me a number.

Why the token names are identical everywhere

Picking a direction is a values decision, not an architecture decision. Whichever one you choose, its :root and [data-theme="dark"] blocks become frontend/src/styles/tokens.css and every CSS Module reads them by name — which is exactly what the runtime cosmetics/theming system in 06-frontend-architecture.md needs. Changing your mind later is a values edit, not a rewrite. See _shared/README.md for the full token list and the constraints each sample already honours.

05Bento Press
